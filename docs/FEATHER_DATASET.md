# Датасет для прогона

Движок не перечисляет контракты. В `Open` уходят два каталога: фьючерсы и опционы. Площадка читает каждый каталог одним проходом, сверху вниз. Слот под символ появляется на его первой строке и снимается на следующий календарный день после даты в имени.

Пути задаются в `trading-engine/options/engine.toml`:

```toml
fut_dataset = "/абсолютный/путь/fut"
opt_dataset = "/абсолютный/путь/opt"
tick_size = "0.0001"
step_ns = 100000000
```

`tick_size` — десятичная строка, `1 / tick_size` обязано быть целым. `step_ns` — шаг часов в наносекундах. `class_code` площадка не читает.

## Дерево

День — каталог `YYYYMMDD`. Имя должно сортироваться как дата: `20260309` раньше `20260310`. Внутри дня одна поставка:

```text
fut/20260309/<job>/manifest.json
fut/20260309/<job>/source-metadata.json
fut/20260309/<job>/part-00000.feather
opt/20260309/<job>/...
```

Площадка обходит каталоги по возрастанию пути, внутри поставки — файлы в том порядке, как они записаны в `manifest.parts`. Строки в этом порядке и есть лента. Время назад по этой ленте идти не может: часы принимают только больший `ts_recv`.

## manifest.json

Нужны три поля. Остальное площадка не смотрит.

| Поле | Смысл |
| --- | --- |
| `schema_name` | `databento_mbp` или `databento_bbo_1m` |
| `price_scale` | Положительное число. Цена в файле — целое, в стакане `цена / price_scale` |
| `parts` | Список `{ "filename": "part-00000.feather" }` |

## source-metadata.json

Связка номера строки с именем. Номер уникален внутри одного дня. В другой день у того же контракта может быть другой номер, если в метаданных этого дня написано его имя.

```json
{
  "mappings": [
    {
      "raw_symbol": "FCEU SI 20260615 PS",
      "intervals": [
        { "symbol": "12" }
      ]
    }
  ]
}
```

`intervals[].symbol` — десятичная строка `instrument_id` из Feather. Каждая строка файла должна находиться в этой карте. Имя без записи в карте площадка пропускает.

## Имя символа

В имени должна быть дата `YYYYMMDD`. Это экспирация. Когда календарный день часов стал больше этой даты, слот удаляется.

```text
FCEU SI 20260615 PS
EUCO SI 20260612 PS EU C 1.1400 0
EUCO SI 20260612 PS EU P 1.1400 0
```

У опциона после даты стоит `C` или `P` и страйк. Точка в страйке обязательна: `1.1400`. Движок по этим кускам собирает цепочку.

## Feather

Файл — Feather V2, одна таблица Arrow IPC. Пустых ячеек нет: колонки не nullable и без null.

Обязательные колонки:

| Колонка | Тип | Смысл |
| --- | --- | --- |
| `ts_recv` | uint64 | Наносекунды Unix. Это время тика |
| `instrument_id` | uint32 | Номер из метаданных этого дня |
| `bid_px_00` | int64 | Лучший бид, fixed-point |
| `ask_px_00` | int64 | Лучший аск |
| `bid_sz_00` | uint32 | Объём на лучшем биде |
| `ask_sz_00` | uint32 | Объём на лучшем аске |

Глубже — те же имена с `_01` … `_63`. Уровень есть, только если есть и цена, и размер. Сторона обрывается на первом уровне, где цена равна `2^63 - 1` или размер `0`. `_00` — лучшая цена: биды по убыванию, аски по возрастанию.

Одна строка — один снимок стакана одного инструмента. Для одного `raw_symbol` метки `ts_recv` вдоль ленты (дни по порядку, внутри дня порядок файла) должны строго расти.

Размер батча площадке не важен. Упаковщик XEUR пишет по 4096 строк и жмёт lz4. Читатель держит в памяти один батч файла и отпускает его, когда переходит к следующему.

## Как это читается

1. Движок шлёт `Open` с двумя компонентами, `sec_code = "*"`, пути `fut_dataset` и `opt_dataset`.
2. Площадка открывает по журналу на каталог и читает строки по порядку дней.
3. Первая строка символа создаёт ему слот. Следующие строки пишутся в тот же слот.
4. На следующий календарный день после `YYYYMMDD` в имени слот удаляется.

Пока у символа нет строк, слота нет. Искать его первую строку заранее не нужно.
